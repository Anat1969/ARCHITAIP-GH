# ארכיטייפ / DWELLING DNA

מגזין ארכיטקטורה תרבותית. כתובת: https://architaip.vercel.app

## מבנה

| כתובת | מה יש בה |
|---|---|
| `/` | שער, תוכן העניינים, אטלס רוחבי (`?v=light` וכו'), מיזוגים |
| `/c/:id` | עמוד תרבות: מנגנון (כאוס, סדר, תפקיד), טקסט, מסורת, DNA, הקרנה. `?space=` פותח מרחב |
| `/f/:id` | עמוד מיזוג, עם שושלת ומשקלים |
| `/lab?p=a,b` | השוואה וקטור מול וקטור, ויצירת מיזוג לעורכת |
| `/read` | ממשיך מהתרבות האחרונה שנקראה |

- `src/store/data.jsx`: כל הנתונים. תרבויות מובנות ב-`src/data/cultures.js`, עריכות ותמונות בטבלאות `architaip_*`.
- `src/store/auth.jsx`: קריאה פתוחה. עריכה למי שרשום ב-`architaip_admins`.
- `src/lib/generate.js`: יצירת תרבות ומיזוג. התוצאה מוצגת לאישור לפני שמירה.
- `supabase/functions/*`: קריאות ל-Claude ול-fal.ai. בודקות שהקורא הוא עורכת.

## הרשאות

אותה רשימה (`architaip_admins`) נבדקת בשלושה מקומות: מדיניות RLS של הטבלאות והדלי, הפונקציות בשרת, והממשק.

## בדיקה

```bash
npm run build
npx vite preview --port 4173 &
CHROME=/opt/pw-browsers/chromium npm run test:e2e
```

הבדיקה מדמה את Supabase כולו, כקוראת וכעורכת, בדסקטופ ובנייד.
